# .github

Archivos de comunidad por omisión para los repositorios de [4-20 Systems](https://onlyfights420.github.io). GitHub los usa en cualquier repositorio de `onlyfights420` que no tenga los suyos.

| Archivo | Para qué |
|---|---|
| [`CONTRIBUTING.md`](./CONTRIBUTING.md) | Las reglas generales y cómo enviar un cambio |
| [`SECURITY.md`](./SECURITY.md) | Cómo reportar una falla de seguridad en privado |
| [`PULL_REQUEST_TEMPLATE.md`](./PULL_REQUEST_TEMPLATE.md) | Plantilla de *pull request* |
| [`ISSUE_TEMPLATE/`](./ISSUE_TEMPLATE/) | Formularios para reportar fallas y proponer ideas |

Este repositorio debe seguir siendo **público**: GitHub solo toma estos archivos por omisión de un `.github` público. Por lo mismo, aquí no va nada privado.
